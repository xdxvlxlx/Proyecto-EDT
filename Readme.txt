
**UrbanRoute** es un sistema de gestión y visualización de redes de transporte desarrollado en Java. Utiliza estructuras de datos personalizadas (tablas hash y listas enlazadas), algoritmos de optimización de rutas (Dijkstra y DFS) y la librería GraphStream para modelar y analizar estaciones de forma interactiva.
